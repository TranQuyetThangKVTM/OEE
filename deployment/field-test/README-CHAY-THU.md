# Script chạy thử đời cũ

Thư mục này chứa launcher của gói field-test cũ có Worker riêng. Solution hiện tại chạy hosted worker bên trong Oee.Web; không dùng quy trình initialize/khởi tạo database cũ để cập nhật máy vận hành.

Quy trình hiện hành: sổ tay kỹ sư trong `output/word/So_tay_ky_su_OEE.docx` và `deployment/iis/README-IIS.md`. Triển khai bằng gói publish phù hợp, giữ cấu hình và dữ liệu máy đích. Các script cũ chưa được viết lại trong đợt dọn tài liệu này.
